Version Control, GitHub Pages, and Course Repository Integration — Topic Prompt (Source)

Module: Version Control and GitHub PreseMaker can put a course under version control and publish it online — all from inside the application. You do not type git commands; PreseMaker performs the git operations for you through its own interface. Managing a course as a git repository. From within PreseMaker you can initialize a git repository for a course, commit your changes with a message, push to a remote, pull, and check for incoming changes or conflicts. PreseMaker stores each course's git settings — such as the remote URL and branch — and remembers when it was last pushed. Branches, pull requests, and manual merge-conflict resolution are general git/GitHub concepts and are not part of PreseMaker's built-in workflow, so this module should describe the actions PreseMaker's interface actually provides, not a command-line git tutorial. Publishing the website with GitHub Pages. After you export a course website, PreseMaker can publish it online through GitHub Pages, giving the course a public web address. PreseMaker assists with connecting the GitHub repository and publishing, so this is done through PreseMaker rather than by hand-configuring settings on the GitHub website. The course repository service. Separately from git, PreseMaker integrates with an external course-repository service (one live example is floridacourserepo.com). Through it you can import course materials from a shared repository and publish your materials to one. This is a content-sharing service for obtaining and distributing course materials — it is not a raw git branch-and-pull-request workflow, and it should not be described using git commands, personal access tokens, or branches. Other sharing options. A course can also be exported as an archive file and imported elsewhere, and an iFrame embed code lets you embed content in another web page.
