Using PreseMaker

Version Control, GitHub Pages, and Course Repository Integration

This module explores how PreseMaker integrates Git-based version control and multiple publishing workflows into a seamless authoring experience. You will learn to manage course repositories, publish live websites via GitHub Pages, share materials through the Course Repository Service, and choose the distribution method that best fits your audience and environment.
