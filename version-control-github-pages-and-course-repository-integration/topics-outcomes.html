Module Topics

Managing a Course as a Git Repository in PreseMaker

Covers how PreseMaker enables version control for courses without command-line git, including initializing a repository, committing changes, pushing to a remote, and pulling updates through PreseMaker's built-in interface.
  • Initializing a Git Repository for a Course — PreseMaker allows you to place any course under version control by initializing a git repository directly from within the application.
  • Committing Changes with a Message — After making edits to a course, you can record a snapshot of those changes by creating a commit through PreseMaker's built-in interface.
  • Pushing Changes to a Remote Repository — Once changes are committed locally, PreseMaker enables you to push those commits to a configured remote repository such as one hosted on GitHub.
  • Pulling Updates from a Remote Repository — PreseMaker also supports pulling changes from a remote repository, allowing you to bring in updates that exist on the remote but not yet on your local copy.
  • Checking for Incoming Changes and Conflicts — Before pulling, PreseMaker allows you to check whether there are incoming changes on the remote that differ from your local version.
  • Stored Git Settings per Course — PreseMaker maintains a set of git configuration details for each course, so you do not need to reconfigure version control every time you work on a project.

Publishing a Course Website with GitHub Pages

Explains how PreseMaker connects a course to GitHub and publishes the exported website through GitHub Pages, giving the course a live public web address without manual configuration on GitHub.
  • Exporting the Course Website Before Publishing — Before PreseMaker can publish a course online, you first export it as a website from within the application.
  • Connecting the Course to a GitHub Repository — PreseMaker handles the connection between your course and a GitHub repository directly through its own interface, without requiring you to configure anything manually on the GitHub website.
  • Publishing Through PreseMaker Rather Than GitHub's Website — PreseMaker assists with the full GitHub Pages publishing process so that you never need to navigate GitHub's settings pages or run git commands manually.
  • The Live Public Web Address — Once published, the course receives a live public web address through GitHub Pages, making it accessible to learners anywhere with a browser.
  • Pushing Updates to the Published Site — When you revise a course and re-export it, PreseMaker lets you push the updated files to the same repository, refreshing the live website.

Using the Course Repository Service

Describes PreseMaker's integration with external course-repository services, covering how to import course materials from a shared repository and publish your own materials for others to access and reuse.
  • What the Course Repository Service Is — PreseMaker integrates with an external course-repository service — such as floridacourserepo.com — that functions as a content-sharing hub for educators.
  • Connecting to the Repository Service from PreseMaker — PreseMaker provides a built-in interface to connect to the course-repository service, keeping the process inside the application.
  • Importing Course Materials from the Repository — Through the course-repository service, you can browse and import course materials that others have published, bringing them directly into PreseMaker for use or adaptation.
  • Publishing Your Materials to the Repository — You can contribute your own course materials to the shared repository through PreseMaker, making them available for other educators to discover and reuse.
  • How the Repository Service Differs from Other PreseMaker Features — The course-repository service fills a distinct role compared to PreseMaker's git integration and GitHub Pages publishing, and it is important to understand where each feature applies.

Other Sharing Options: Archive Export and iFrame Embedding

Introduces additional ways to share course content, including exporting a course as a portable archive file for import elsewhere and generating an iFrame embed code to display course content within another web page.
  • Overview of Additional Sharing Options — Beyond version control and GitHub Pages, PreseMaker provides two supplementary methods for distributing course content to different audiences and platforms.
  • Exporting a Course as an Archive File — PreseMaker can export an entire course as a self-contained archive file, making the course portable and importable into another environment.
  • When to Use Archive Export — Archive export is best suited for situations where a portable, standalone copy of the course is needed rather than a live published link.
  • Generating an iFrame Embed Code — PreseMaker can generate an iFrame embed code that allows course content to be displayed directly within another web page.
  • When to Use iFrame Embedding — iFrame embedding is the preferred option when course content needs to appear seamlessly within an existing website or learning management system page.
  • Comparing Archive Export and iFrame Embedding — Although both options extend how course content is shared, they serve distinct purposes and suit different distribution scenarios.

Choosing the Right Sharing Method

Helps learners compare all available sharing and distribution options — version control, GitHub Pages, course repository, archive export, and iFrame — so they can identify which best fits a given use case.
  • Overview of Available Sharing Methods — PreseMaker offers several distinct ways to share and distribute course content, each serving a different purpose and audience.
  • Version Control for Ongoing Course Development — Using PreseMaker's built-in git integration is best suited for tracking changes over time and maintaining a reliable history of a course.
  • GitHub Pages for Public Web Publishing — GitHub Pages takes an exported course website and gives it a live, public web address that anyone can visit in a browser.
  • The Course Repository Service for Content Sharing — The course repository service (such as floridacourserepo.com) is a dedicated platform for discovering, importing, and publishing reusable course materials within a community.
  • Archive Export for Portable, Offline Distribution — Exporting a course as an archive file packages all course content into a single transferable file that can be imported into another PreseMaker instance.
  • iFrame Embedding for Integration with Other Platforms — An iFrame embed code lets you display course content inside an existing web page, learning management system, or other platform without redirecting learners to a separate site.
  • Matching the Method to the Use Case — Each sharing method has a specific sweet spot, and the best choice depends on the combination of your collaboration needs, audience, and technical environment.
