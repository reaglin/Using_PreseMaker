Using PreseMaker

Building a Standards Library and Mapping Topics to Standards

This module walks you through the full workflow of creating and managing a Standards Library in PreseMaker — from using AI to extract and organize standards frameworks, to understanding verification markers, applying Bloom's Taxonomy cognitive levels, and mapping course topics and learning outcomes to specific standards. Use the resources below to explore each aspect of the process.
