Using PreseMaker

Building a Standards Library and Mapping Topics to Standards

This module guides you through setting up a centralized Standards Library in PreseMaker, using AI to extract and organize frameworks, interpreting verification markers, applying Bloom's Taxonomy cognitive levels, and creating explicit mappings between course topics, learning outcomes, and standards.

What Is the Standards Library

This reading explains what the Standards Library feature is in PreseMaker, describing how it provides a centralized location to store, organize, and manage external academic or professional standards frameworks so course designers can efficiently align course content to those standards.

Topic Detail .html
Building the Library with AI

A lesson explaining how to use PreseMaker's AI to automatically extract and organize standards from a framework, covering what input to provide, how the AI processes it, and how to review the results.

Topic Detail .html
Understanding the Verified and Unverified Markers

This reading clarifies the meaning of the Verified and Unverified markers that appear on standards in the Standards Library, warning learners that these labels do not indicate an approval workflow and explaining what they actually signify to prevent misuse that could cause alignment errors.

Topic Detail .html
Cognitive Levels on Standards

A lesson covering how Bloom's Taxonomy cognitive levels apply to standards in PreseMaker, explaining why matching the cognitive demand of a standard matters when designing topics and learning outcomes.

Mapping Topics and Learning Outcomes to Standards

A lesson explaining how to create explicit, documented connections between course topics, learning outcomes, and specific standards in PreseMaker, guiding instructors through the mapping process.
