Understanding Question Types

Explores the range of question types available for building question banks, such as multiple choice, short answer, and true/false. Learners understand when and why to use each type for effective assessment.
  • Multiple Choice Questions — Multiple choice questions (MCQs) present a stem prompt alongside several answer options, with one or more correct answers.
  • True/False Questions — True/false questions ask learners to evaluate a single declarative statement and determine whether it is correct or incorrect.
  • Short Answer Questions — Short answer questions require learners to produce a brief written response—typically a word, phrase, or a few sentences—rather than selecting from options.
  • Matching and Other Structured Question Types — Beyond the core three types, question banks can include matching, ordering, multiselect, and written-response formats that add variety and target specific learning outcomes.
  • Choosing the Right Question Type for the Learning Outcome — Selecting an appropriate question type is a deliberate instructional decision driven by the learning outcome being assessed and the cognitive level it targets.
  • Building a Balanced Question Bank — A question bank is a repository of categorized questions from which quizzes and assignments are drawn, and balance across question types strengthens its overall effectiveness.

Using the Content Source Selector

Guides learners through targeting specific topics and learning outcomes using the content source selector tool. Ensures that generated assessments are aligned with the module plan and intended learning goals.
  • What Is the Content Source Selector? — The content source selector is a tool that allows you to specify which topics, outcomes, or sections of your module plan should inform the generated assessment content.
  • Locating and Opening the Selector — Before generating a quiz or assignment, learners must navigate to the content source selector within the assessment generation interface.
  • Targeting Specific Topics — Once the selector is open, you can drill down to individual topics within your module to focus the assessment on a precise area of content.
  • Aligning with Intended Learning Outcomes — Beyond topics, the content source selector allows you to target specific learning outcomes, ensuring each generated question maps to a measurable goal.
  • Confirming Your Selection Before Generating — After making your topic and outcome selections, it is important to review and confirm your choices to avoid generating misaligned content.
  • How Selector Choices Influence Generated Output — The topics and outcomes you select directly shape the content, vocabulary, and cognitive level of the questions and tasks that are generated.

Building and Generating Question Banks

Covers the step-by-step process of configuring and generating a question bank based on selected content sources and question types. Learners practice creating comprehensive banks ready for use in assessments.
  • Selecting Content Sources for the Question Bank — The first step in building a question bank is identifying and selecting the specific content sources that will drive question generation.
  • Choosing Question Types for the Bank — A comprehensive question bank draws on multiple question types to assess learners at different cognitive levels.
  • Configuring Question Bank Parameters — Before generating, learners must configure key parameters that control the scope, depth, and structure of the question bank.
  • Generating the Question Bank — Once sources and parameters are configured, the generation step produces the full set of questions ready for review.
  • Reviewing and Editing Generated Questions — After generation, each question in the bank should be reviewed for accuracy, clarity, and alignment before the bank is finalized.
  • Organizing and Tagging Questions in the Bank — Organizing questions with tags, categories, or metadata makes the question bank easier to manage and reuse across multiple assessments.
  • Finalizing the Question Bank for Assessment Use — The final step is confirming the question bank is complete, accurate, and ready to be deployed in quizzes or assignments.

Exporting to LMS-Compatible Formats

Explains how to export generated question banks into formats compatible with popular learning management systems. Addresses format options, export settings, and best practices for seamless LMS integration.
  • Understanding LMS-Compatible Export Formats — Different learning management systems support different file formats for importing question banks and assessments. Choosing the correct format before exporting ensures your content can be uploaded without manual rework.
  • Selecting the Right Export Format for Your LMS — Matching your export format to your specific LMS version and configuration is a critical first step. Mismatched formats can result in failed imports or loss of question data.
  • Configuring Export Settings — Export settings allow you to control what metadata, question types, and structural elements are included in the exported file. Properly configured settings reduce the need for post-import corrections inside the LMS.
  • Exporting Question Banks Aligned to Topics and Outcomes — Before exporting, use the content source selector to ensure the question bank is scoped to the correct topics and learning outcomes. This alignment guarantees that exported assessments reflect the intended module plan.
  • Best Practices for Seamless LMS Integration — Following a consistent export and import workflow minimizes errors and ensures assessment content functions as intended inside the LMS. Establishing best practices saves time across repeated export cycles.
  • Troubleshooting Common Export and Import Issues — Even with careful preparation, export and import processes can produce errors due to format mismatches, unsupported question types, or encoding issues. Knowing how to identify and resolve common problems speeds up the integration process.

Creating Structured Assignment Tasks

Focuses on producing well-structured assignment tasks that align with module outcomes and learner needs. Learners explore how to define task parameters, instructions, and evaluation criteria during generation.
  • Defining Task Parameters — Before generating an assignment task, it is essential to establish clear parameters that shape the scope and expectations of the work.
  • Aligning Tasks with Module Outcomes — Effective assignment tasks must directly connect to the module's learning outcomes to ensure learners are assessed on the right competencies.
  • Writing Clear and Complete Instructions — Well-structured assignment tasks include precise instructions that tell learners exactly what is expected of them.
  • Defining Evaluation Criteria — Evaluation criteria make the basis for grading transparent and help learners understand how their work will be assessed.
  • Structuring the Assignment Layout — The physical structure and formatting of an assignment task influence how clearly learners receive and interpret it.
  • Adapting Tasks to Learner Needs — Structured assignment tasks should be tailored to the profile, prior knowledge, and context of the intended learner group.

Aligning Assessments with the Module Plan

Reinforces strategies for ensuring consistency and alignment between generated quizzes, assignments, and the overall module plan. Learners review and validate their assessments against intended topics and outcomes.
  • Understanding Assessment Alignment — Assessment alignment means ensuring that every quiz question and assignment task directly corresponds to the intended topics and learning outcomes in your module plan.
  • Using the Content Source Selector for Targeted Generation — The content source selector allows you to specify which topics and outcomes should inform the quiz or assignment being generated, ensuring relevance from the start.
  • Mapping Questions and Tasks to Learning Outcomes — After generating a quiz or assignment, each item should be explicitly traced to one or more learning outcomes listed in the module plan.
  • Reviewing Generated Assessments Against the Module Plan — A structured review process compares the full set of generated questions and assignments against the module plan to confirm completeness and consistency.
  • Validating Assignments for Outcome Consistency — Structured assignment tasks must also be validated to confirm that their instructions, deliverables, and criteria reflect the intended learning outcomes of the module.
  • Iterating to Achieve Full Alignment — Alignment is rarely perfect on the first generation pass; an iterative cycle of generating, reviewing, adjusting, and re-validating is the recommended workflow.
