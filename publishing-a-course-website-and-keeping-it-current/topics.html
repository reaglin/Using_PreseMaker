Keeping the Course Website Current

Covers best practices and workflows for re-publishing and maintaining an up-to-date course website as module content evolves over time.
  • Understanding Why Re-Publishing Is Necessary — Each time module content changes, the HTML index for that module must be refreshed before the course website accurately reflects those updates.
  • Identifying When to Re-Publish — Knowing the right triggers for re-publishing helps maintain a consistently accurate course website without unnecessary extra work.
  • The Re-Publishing Workflow in PreseMaker — Re-publishing a course website in PreseMaker follows the same core steps as the initial publish, ensuring each module's HTML index is rebuilt before the site is assembled.
  • Managing Multiple Modules During Updates — Courses with several modules require careful coordination to ensure every changed module is re-published and no landing page is left outdated.
  • Verifying the Updated Course Website — After re-publishing, a review step confirms that all changes appear correctly across the live course website and each module's landing page.
  • Establishing a Maintenance Cadence — Setting a regular schedule or clear policy for re-publishing keeps the course website reliably current without requiring ad hoc decisions each time content changes.
