# Using PreseMaker

This is a course on how to use the PreseMaker Application.

## Modules

1. Introduction to PreseMaker: What It Is and How It Works
2. Understanding the Course-Module-Content Structure
3. AI Providers and API Keys: Setting Up Your Connection
4. Configuring AI Providers per Task and Using the Prompt Button
5. Creating a Course: The Course Manager and Source Materials
6. Generating a Module Breakdown from Source Material
7. Creating a Module: Three Methods and the Module Manager
8. Generating Module Topics and Subtopics
9. Generating Module Learning Outcomes with Bloom's Taxonomy
10. Generating Presentations and Narrated Presentations
11. Generating Text-Based Lessons: Formats, Layouts, and Content Types
12. Generating Quizzes and Assignments
13. Generating Interactive Activities and Custom Materials
14. The Module Index: Cataloguing and Viewing Generated Content
15. Course Outcomes vs. Module Outcomes and the Alignment Map
16. Tracking Coverage: Tagging Content to Outcomes and Spotting Gaps
17. Batch Actions: Generating Content Across Multiple Modules at Once
18. Common Actions: Running Multiple Tasks for a Single Module Together
19. Publishing a Course Website and Keeping It Current
20. Version Control, GitHub Pages, and Course Repository Integration
21. Building a Standards Library and Mapping Topics to Standards
22. Reading Standards Coverage and Checking Cognitive Depth
