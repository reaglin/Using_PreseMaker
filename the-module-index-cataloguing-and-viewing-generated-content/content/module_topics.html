The Module Index: Cataloguing and Viewing Generated Content — Module Topics

What Is the Module Index?

Introduces the Module Index as the central catalogue of all artifacts produced within a module. Explains its dual role as both a record-keeping tool and a content viewer.
  • Defining the Module Index — The Module Index is the central catalogue that records every artifact produced within a module. It acts as a single, authoritative reference point for all generated content.
  • The Record-Keeping Role — One of the Module Index's two core functions is to serve as a persistent record of all module artifacts. This ensures nothing produced during the module is lost or overlooked.
  • The Content Viewer Role — Beyond record-keeping, the Module Index also functions as a unified viewer for opening and reviewing generated files. Users do not need to search external folders or systems to access content.
  • The HTML Index as a Self-Contained Browsable Version — The Module Index includes an HTML version that serves as a browsable landing page for the module, linking to its generated files. This format lets you navigate the module in a standard web browser.
  • Why a Centralised Catalogue Matters — Having a single, centralised catalogue prevents fragmentation of generated content across multiple locations. It gives learners and instructors confidence that they are working with the complete picture.

Opening and Reviewing Generated Files

Explains the process of opening individual artifacts directly from the Module Index. Covers how to review and interact with generated content within the viewer.
  • Locating an Artifact in the Module Index — Before opening a file, you must first locate it within the Module Index catalogue. The Module Index lists every artifact produced in a module, giving you a single point of access for all generated content.
  • Opening an Artifact Directly from the Index — Individual artifacts can be opened directly from the Module Index with a single interaction. This direct-open capability means you do not need to navigate away from the index or locate files manually in a file system.
  • Using the Integrated Viewer to Review Content — Once an artifact is opened, the integrated viewer provides an environment for reading and interacting with the generated content. The viewer is designed to render files clearly without requiring external applications.
  • Interacting with Content Inside the Viewer — The viewer is not purely passive — it allows you to interact with the displayed content in meaningful ways. Interaction options may include selecting text, following internal links, or navigating between sections.
  • Returning to the Module Index After Review — After reviewing an artifact, you can return to the Module Index to open additional files or continue cataloguing. The index remains the central hub throughout your session.
  • Reviewing Content via the HTML Index — The Module Index also exists as a self-contained HTML file that serves as a browsable version of the entire module. This HTML index allows you to open and review generated artifacts in a standard web browser.

The HTML Index as a Self-Contained Browsable Module

Describes how the HTML index functions as a browsable landing page for the entire module. Highlights how to move or share it (keep its output folder together) and its use as an offline reference.
  • What the HTML Index Is — The HTML index is a browsable landing page that links to the module's generated files, presenting the whole module in a web browser.
  • Portability of the HTML Index — Because the HTML index and the files it links to live in one output folder, moving or copying that whole folder preserves its functionality.
  • Using the HTML Index Offline — The HTML index is designed to function entirely offline, making module content accessible in environments without internet connectivity.
  • The HTML Index as a Shareable Reference — The HTML index serves as a ready-made reference document that can be shared with others who did not participate in the original module session.
  • Navigating Content Within the HTML Index — The HTML index provides an interactive browsing experience that lets users move through the module's content elements in an organised way.
  • The HTML Index as a Complete Module Snapshot — At any point in time, the HTML index represents a full snapshot of everything generated within the module up to that moment.
