  • Navigating the Course Manager Interface — The Course Manager interface is designed to give users a clear overview of all existing courses and quick access to key actions.
  • The Course Manager's Role in the Overall Workflow — The Course Manager connects all phases of course development, acting as the consistent reference point throughout the PreseMaker workflow.

Creating a New Course

Learners will walk through the process of creating a new course in PreseMaker, including the choice between starting with an empty course or using AI to generate one. This topic covers the initial setup steps and available creation options.
  • The Course Manager as Your Starting Point — The Course Manager is the home screen of PreseMaker and the place where all course creation begins.
  • Initiating the Course Creation Process — Creating a new course in PreseMaker begins by selecting the option to create a new course from within the Course Manager.
  • Choosing Between an Empty Course and AI Generation — PreseMaker offers two primary paths for creating a new course: starting with an empty course or using AI to generate one.
  • Starting with an Empty Course — Choosing the empty course option creates a course with no pre-filled content, giving authors full manual control over structure and material.
  • Using AI to Generate a New Course — The AI-generation option allows PreseMaker to automatically produce an initial course structure and content based on information you supply.
  • Completing the Initial Course Setup — Regardless of which creation path is chosen, there are essential setup steps required before the course is fully initialized in PreseMaker.

AI-Generated Course Creation

This topic explores how PreseMaker's AI can automatically generate a course structure based on provided inputs. Learners will understand when and why to choose AI generation over manual course building.
  • What Is AI-Generated Course Creation? — PreseMaker's AI-generated course creation automatically builds a course structure based on inputs you provide, rather than requiring you to manually assemble every component.
  • When to Choose AI Generation Over Manual Building — Choosing between AI-generated and manual course creation depends on your timeline, the complexity of your content, and how much structure already exists in your source materials.
  • Inputs That Drive AI Course Generation — The quality and type of inputs you provide directly influence how well the AI constructs your course structure.
  • The Role of Primary vs. Secondary Sources in AI Generation — PreseMaker distinguishes between primary and secondary source materials, and this distinction affects how the AI prioritizes and uses your inputs during course generation.
  • Initiating AI Course Generation in PreseMaker — Starting an AI-generated course in PreseMaker involves selecting the AI generation option when creating a new course from the Course Manager.

Accepted Source Material Types

PreseMaker supports a variety of source material formats including PowerPoint files, written descriptions, documents, web pages, pasted text, and YouTube transcripts. Learners will explore each type and understand how they are used to populate course content.
  • PowerPoint Files — PreseMaker accepts PowerPoint files (.pptx) as a source material type, allowing existing slide decks to be used as the foundation for course content.
  • Written Descriptions — A written description is a plain-text summary or overview that tells PreseMaker what the course should be about, enabling AI-generated content creation from scratch.
  • Documents — PreseMaker supports uploaded documents such as Word files or PDFs as source materials, extracting their text content to inform course structure and content.
  • Web Pages — PreseMaker can accept URLs to web pages as source material, pulling content directly from online resources to help build course content.
  • Pasted Text — Pasted text allows users to copy and paste any written content directly into PreseMaker, providing maximum flexibility in sourcing material from various origins.
  • YouTube Transcripts — PreseMaker supports YouTube video URLs as a source material type by extracting the video's transcript to generate course content.

Primary vs. Secondary Sources

Learners will understand the distinction between primary and secondary source materials within PreseMaker and how each type influences the course structure and AI generation process.
  • Defining Primary Sources in PreseMaker — A primary source is the main input material that drives the AI generation process when building a course in PreseMaker.
  • Defining Secondary Sources in PreseMaker — Secondary sources are supplemental materials provided alongside the primary source to enrich or add context to the generated course content.
  • How Source Designation Affects AI Generation — The way PreseMaker's AI generates course content is directly shaped by which material is marked as primary versus secondary.
  • Accepted Source Material Types — PreseMaker supports a variety of file and content formats that can be used as either primary or secondary sources when creating a course.
  • Choosing the Right Primary Source — Selecting an appropriate primary source is a strategic decision that determines the direction and coherence of the entire AI-generated course.
