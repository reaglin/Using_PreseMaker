Using PreseMaker

Generating Quizzes and Assignments

This module covers the end-to-end process of creating, configuring, and exporting quizzes and assignments inside PreseMaker — from choosing the right question types and using the Content Source Selector, to building reusable question banks, structuring assignment tasks, and ensuring every assessment aligns with your module's learning outcomes.
