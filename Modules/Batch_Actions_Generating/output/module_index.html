Batch Actions: Generating Content Across Multiple Modules at Once

This module explores how to use PreseMaker's batch actions feature to efficiently generate content across many modules simultaneously. Topics range from understanding what batch actions are and selecting content types, through configuring and launching a run, to monitoring live progress and stopping a run safely when needed.
