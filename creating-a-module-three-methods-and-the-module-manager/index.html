Using PreseMaker

Creating a Module: Three Methods and the Module Manager

This module introduces the three ways to create a module in PreseMaker — AI-powered generation, adding an existing folder from disk, and importing from a file or repository — and shows how every pathway converges in the Module Manager, the central hub for module configuration and setup. Work through the topics below to build a complete picture of the module creation lifecycle.
