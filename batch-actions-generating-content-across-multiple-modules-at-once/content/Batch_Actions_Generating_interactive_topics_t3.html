Choosing and Configuring Modules for a Batch Run

▶

When you need to generate learning content across an entire course at once, manually working through each module one by one is time-consuming and inconsistent. The batch run feature solves this by letting you select multiple modules, choose a content type, configure settings, and trigger generation for all of them in a single operation. Understanding how to navigate to batch actions, make smart module selections, and configure settings correctly ensures you get consistent, high-quality output across your course without redundant effort.

Batch actions operate at the course level, not at the individual module level. This is an important distinction. When you are inside a single module editing its details or reviewing its topics, you will not find the batch action controls there. Instead, you need to step back to the Course Manager, which provides a course-wide view of all your modules together. Think of the Course Manager as the command center for your entire course — it is the place where you can see every module at a glance and apply actions that span across all of them simultaneously. Before you begin, confirm that your course already has at least one module with generated topics in place. The batch content generation actions — such as generating quizzes, presentations, or text documents — depend on topic data already existing within the modules. If your modules are empty shells without topics, the AI will not have the context it needs to produce meaningful content.

Once you are in the Course Manager and have located the Batch Actions feature, your first task is deciding which modules to include in the run. The module selection interface presents you with a list of all modules in your course, each with a checkbox or toggle that lets you include or exclude it. For courses with many modules, a Select All option lets you check every module instantly — this is the most efficient starting point when you want broad coverage. From there, you can deselect any modules that should be excluded from the current batch. Common reasons to exclude a module might include modules that are still being drafted, modules where content has already been generated and does not need to be regenerated, or modules that require a different configuration than the rest of the batch. Reviewing your selection carefully before proceeding is essential: the batch action will attempt to generate content for every checked module, so an accidental inclusion can result in unwanted content being produced that then needs to be reviewed or deleted.

With your modules selected, the next step is choosing the type of content to generate. Batch actions are not a single one-size-fits-all command — they are separate, distinct actions, each targeting a specific content format. The available options typically include:

  • Generate Module Topics and Outcomes — creates the topic structure and learning outcomes for each selected module, useful when building a course from scratch or restructuring existing modules.
  • Generate Quizzes — produces assessment questions tied to the content of each selected module's topics.
  • Generate Presentations — builds slide-based presentation content derived from the module topics, suitable for lectures or learner-facing slide decks.
  • Generate Text Documents — creates written learning materials, such as reading content or study guides, based on the module topics.

You run one batch action at a time. If you need both quizzes and presentations for the same set of modules, you will run the quiz batch first, then return and run the presentation batch separately, selecting the same modules again. This design gives you precise control — you are never forced to generate every content type at once, and you can stage your production in whatever order matches your workflow.

After selecting your content type, you will reach the batch settings configuration screen, where you define the parameters that the AI will apply uniformly to all selected modules in this run. The available settings differ depending on which content type you chose:

Content Type Key Settings to Configure
Quizzes Number of questions, question types (multiple choice, true/false, short answer, etc.), optional hints, optional feedback per answer
Presentations Target audience, tone (formal, conversational, instructional), number of slides per module
Text Documents Document format (e.g., structured notes, narrative prose), theme or instructional focus

Because these settings are applied uniformly across all selected modules, it is worth pausing to think about whether a single configuration truly fits every module you have checked. For example, if your course includes both introductory modules intended for beginners and advanced modules for experienced practitioners, a single audience setting in a presentation batch may not be ideal for every module. In cases like this, you have two practical options: run separate batch actions — one for the introductory modules with beginner-level settings, and another for the advanced modules with different settings — or accept the uniform settings and make manual adjustments to individual outputs after the batch completes. Neither approach is wrong; the right choice depends on how much variation exists across your modules and how much post-generation editing you are prepared to do.

The AI draws on course-level context and individual module titles to shape the content it generates. This means the quality and relevance of the batch output is directly tied to how well your course details are filled in and how descriptive your module titles are. A module titled Unit 3 gives the AI very little to work with, while a module titled Managing Conflict in Remote Teams provides rich context that will produce far more targeted and useful content. Before running a batch, take a moment to review your module titles and course description to ensure they accurately represent what each module covers. This small investment of time pays significant dividends in the quality of the generated output.

The final step before launching the batch run is a confirmation review. At this stage, you should methodically check three things. First, scan the list of selected modules one more time — confirm that every module you intended to include is checked, and that no module you intended to exclude has been accidentally left checked. Second, verify that the content type you selected matches your current goal. It is easy to proceed with the wrong action type selected if you were previously exploring the interface. Third, review the configured settings one final time to ensure question counts, slide numbers, tone settings, and any other parameters reflect your intentions for this batch. When you are confident that everything is correct, click the designated Start or Run button to initiate the batch action. The system will begin processing each selected module in sequence, applying your chosen content type and settings to each one. Depending on the number of modules selected and the complexity of the content type, this process may take some time to complete, after which you can review the generated content within each module.

NotesInstructors should be encouraged to test batch settings on a small selection of two or three modules before running a full course-wide batch, especially when working with a new content type or unfamiliar settings. This allows them to review representative output and adjust settings before committing to a full run.
