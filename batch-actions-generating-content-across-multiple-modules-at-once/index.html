Batch Actions: Generating Content Across Multiple Modules at Once

This module introduces PreseMaker's Batch Actions feature, showing you how to generate content across multiple course modules simultaneously. Explore the topics and resources below to learn how to select content types, configure and launch batch runs, monitor live progress, and stop a run safely when needed.
