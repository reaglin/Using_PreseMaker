Module Topics

Introduction to Batch Actions in Course Manager

Introduces the Batch Actions feature available at the course level, explaining its purpose and the types of content that can be generated across multiple modules simultaneously.
  • What Are Batch Actions? — Batch Actions is a course-level feature in Course Manager that allows instructors to generate content across multiple modules in a single operation.
  • Purpose of Batch Actions — The primary purpose of Batch Actions is to improve efficiency by letting instructors scale content creation across an entire course simultaneously.
  • Types of Content That Can Be Generated — Batch Actions support the generation of several content types, each of which can be applied across multiple modules in one run.
  • Course-Level Access to Batch Actions — Batch Actions are accessed from the course level within Course Manager, distinguishing them from actions taken inside individual modules.
  • Scope of a Batch Run — A single batch run can encompass many modules within a course, with instructors selecting which modules to include before generation begins.

Selecting Content Types for Batch Generation

Covers the separate batch actions you can run — Generate Module Topics and Outcomes, Generate Quizzes, Generate Presentations, and Generate Text documents — and how to choose the one you need.
  • Overview of Available Content Types — When setting up a batch run, you must first select which type of content you want the system to generate across your chosen modules.
  • Generating Topics in Batch — Choosing 'Topics' as the content type generates the structured topics for each selected module and, in the same run, the module's learning outcomes.
  • Generating Outcomes in Batch — Selecting 'Outcomes' is not a separate step: outcomes are produced together with topics by the Generate Module Topics and Outcomes action for every module included in the batch.
  • Generating Quizzes in Batch — The 'Quizzes' content type option directs the batch process to create assessment questions tied to the content of each selected module.
  • Generating Presentations and Text Documents in Batch — Batch generation also supports creating slide-based presentations or written text documents, giving instructors flexible output formats for module content.
  • Matching Content Type to Module Needs — Choosing the right content type requires evaluating where each module currently stands in its development and what it still needs.

Choosing and Configuring Modules for a Batch Run

Explains how to select which modules to include in a batch action and how to configure the batch settings before initiating a run.
  • Accessing Batch Actions in the Course Manager — Batch Actions are initiated from within the Course Manager, the central hub for managing your course structure and content generation.
  • Selecting Which Modules to Include — Before running a batch action, you must choose which specific modules will be included in the run, giving you precise control over scope.
  • Choosing the Content Type to Generate — A key configuration step is specifying what type of content the batch action will produce across all selected modules.
  • Reviewing and Configuring Batch Settings — Beyond selecting modules and content type, additional batch settings allow you to fine-tune how content is generated across the run.
  • Confirming Your Selections Before Initiating — A final review step before launching the batch run ensures all modules, content types, and settings are correctly configured.

Monitoring Live Batch Progress

Describes how to read and interpret the live progress indicators displayed during an active batch run to track generation status across modules.
  • The Live Progress Panel — When a batch run is active, a live progress panel appears on screen to give real-time visibility into the generation process across all selected modules.
  • Per-Module Status Indicators — Each module included in the batch displays its own individual status indicator, allowing instructors to see exactly where generation stands for every module at a glance.
  • Overall Batch Completion Counter — In addition to individual module indicators, the progress panel displays an overall completion counter that summarizes how many modules have finished out of the total selected.
  • Reading Generation Order and Queue Position — Batch runs process modules sequentially or in a defined order, and the progress panel reflects this queue so instructors understand which module is being worked on next.
  • Interpreting Error or Warning Signals — The progress panel surfaces errors or warnings for individual modules without stopping the entire batch, ensuring instructors can identify issues while other modules continue generating.
  • Tracking Completion to Know When the Batch Has Finished — The progress panel provides a clear final state indicator so instructors know definitively when the entire batch run has concluded and all results are ready to review.

Stopping a Batch Run Safely

Covers how to halt a batch run mid-process while ensuring that all content already generated in completed modules is preserved and not lost.
  • Understanding the Stop Function — The Stop function allows you to interrupt a batch run at any point during processing without losing the work that has already been completed.
  • When to Stop a Batch Run — Knowing the right moment to stop a batch run helps you minimize wasted processing and protect the quality of your generated content.
  • How Completed Modules Are Preserved — Any module that has fully finished processing before the stop command is issued retains all of its generated content automatically.
  • What Happens to In-Progress Modules — A module that is actively being processed at the moment you stop the run may not produce complete or usable content.
  • Resuming or Rerunning After a Stop — After safely stopping a batch run, you have the option to launch a new batch run targeting only the modules that were not yet completed.
