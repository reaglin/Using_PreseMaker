Obtaining Your API Key

▶

PreseMaker uses artificial intelligence to help you build presentations, but to do that it needs to communicate with an external AI service on your behalf. That communication is authenticated through an API key — a long, unique string of characters that acts like a private password between PreseMaker and your chosen AI provider. Before you can use any AI-powered features in PreseMaker, you must obtain one of these keys from a provider, copy it safely, and enter it into PreseMaker's Settings screen. This section walks you through every step of that process, from picking a provider to confirming your key is ready to use.

PreseMaker is compatible with four AI providers: Anthropic Claude, Google Gemini, OpenAI, and Mistral. Each of these is an independent company with its own platform, pricing, and sign-up process. Because they are separate services, you will need a separate account — and therefore a separate API key — for each provider you want to use. You are not required to sign up with more than one; choosing a single provider and obtaining one key is all PreseMaker needs to get started. If you later decide to switch to a different provider, you can do so by repeating this process with the new provider and entering the new key into PreseMaker at that time. Your old key will remain valid with its original provider but will simply no longer be used by PreseMaker until you enter it again.

To help you decide which provider to start with, here is a brief comparison of what each one offers:

Once you have chosen a provider, your first step is to create an account on that provider's official developer portal or console. Use the URLs in the table above, or search for the provider's name followed by "API" or "developer console" to find the correct site. Avoid third-party sites that claim to offer API keys, as these are not legitimate sources. On the provider's site, look for a Sign Up or Get Started button and complete the registration form. You will typically need to supply:

  • A valid email address, which you will use to verify your account
  • A password for the developer console
  • Your name and, in some cases, your organization or intended use

After submitting the form, check your email inbox for a verification message and click the confirmation link. Some providers — particularly OpenAI and Anthropic — may also ask for a phone number to send a one-time verification code, or they may require you to enter billing information (a credit or debit card) before they grant you API access. This does not necessarily mean you will be charged immediately; many providers offer a free trial credit when you first sign up. However, API usage is generally a paid service, and your account must be in good standing for your key to function correctly. Complete any required billing or verification steps before moving on.

With your account created and verified, log in to the developer console and locate the section where API keys are managed. The exact name and location of this section varies slightly by provider, but you are generally looking for one of the following:

  • Anthropic Console: Click your account name or avatar in the top-right corner, then choose API Keys from the menu.
  • Google AI Studio: Look for a Get API Key button on the main dashboard, or navigate to the left-hand panel and select API Keys.
  • OpenAI Platform: From the left sidebar, select API Keys under your account section, or go to Settings → API Keys.
  • Mistral Console: Click on API Keys in the left navigation panel of the console.

If you cannot immediately find an "API Keys" section, look for menu items or tabs labeled Access Tokens, Credentials, Developer Settings, or simply Keys. These are all common alternative labels that different providers use for the same concept.

Once you are on the API Keys page, you are ready to generate a new key. Click the button that creates a new key — it is commonly labeled Create Key, Generate API Key, + New Key, or simply Generate. A dialog box or form may appear asking for additional details before the key is created. The most useful option at this stage is the key name or description field. Although this is often optional, it is strongly recommended that you enter a descriptive name such as:

PreseMaker - My Laptop

or

PreseMaker Production Key

Giving your key a clear, recognizable name means that later — if you have multiple keys for different applications — you can immediately identify which key belongs to PreseMaker without having to guess. Once you confirm the creation, the provider will generate the key and display it on screen.

This is a critical moment: most providers display the full API key string only once. As soon as the key is shown, you must copy it immediately. Do not close the dialog or navigate away from the page before doing so. The key will typically look something like one of these formats, depending on your provider:

sk-proj-AbCdEfGhIjKlMnOpQrStUvWxYz1234567890abcdefghij
AIzaSyD-XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
sk-ant-api03-XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX

Use the copy icon or button next to the key if one is provided — this reduces the risk of accidentally copying extra whitespace or missing a character. If there is no copy button, carefully click at the very beginning of the key string, drag to select the entire string, and then copy it using your keyboard shortcut (Ctrl+C on Windows, Cmd+C on Mac). The key may be 40 to over 100 characters long depending on the provider, so take care to select all of it.

Immediately after copying, store the key somewhere secure until you are ready to paste it into PreseMaker. The best option is a password manager such as 1Password, Bitwarden, or the built-in password manager in your browser. If you do not use a password manager, a private, encrypted note is the next best option. What you should never do with your API key:

  • Paste it into a public forum, chat, or social media post
  • Include it in an email, especially an unencrypted one
  • Commit it to a code repository (such as GitHub), even a private one
  • Write it in a plain-text file stored in a shared or cloud-synced folder without encryption

The reason these precautions matter is that your API key is directly linked to your provider account and its associated billing. Anyone who obtains your key can make API requests that are charged to your account. If a key is ever accidentally exposed, you should return to the provider's API Keys page, delete or revoke the compromised key immediately, and generate a fresh one.

Before leaving the provider's console, take a moment to confirm that your new key is active. Return to the API Keys list — the key you just created should now appear in the list with a status indicator such as Active, Enabled, or a green checkmark. If it shows as Inactive, Pending, or Restricted, this usually means one of the following:

  • Your email address has not yet been verified — check your inbox and complete the verification step.
  • Your billing information is missing or a payment method has not been confirmed — navigate to the billing section of your account and resolve any outstanding requirements.
  • Your account is still under review — some providers, particularly Anthropic, may have a short review period for new accounts. In this case, you may need to wait before the key becomes usable.

An inactive or unverified account will result in authentication errors when PreseMaker tries to use the key, so it is worth confirming everything is in order now rather than troubleshooting later. Once your key appears as active in the provider's console, and you have it safely copied, you have everything you need. The next step is to open PreseMaker's Settings screen and paste the key into the appropriate API key field — at which point PreseMaker will be fully connected to your chosen AI provider and ready to use.

NotesLearners should be reminded to keep their browser open on the provider console until they have successfully pasted the key into PreseMaker, in case they need to regenerate it. It may also be worth noting that free-tier limits vary significantly between providers and that hitting a usage limit will also cause authentication-style errors in PreseMaker.
