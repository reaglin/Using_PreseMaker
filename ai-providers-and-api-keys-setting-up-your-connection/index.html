Using PreseMaker

AI Providers and API Keys: Setting Up Your Connection

This module covers everything you need to connect PreseMaker to an external AI provider. You will learn how PreseMaker communicates with AI services, what API keys are and how to obtain them, how to enter and save your key in PreseMaker's settings, and how your credentials are stored securely on your device.

How PreseMaker Connects to AI Providers

An explanatory reading that describes how PreseMaker relies on external AI providers to deliver features like content generation and smart suggestions, and why a direct API connection to those providers is necessary; learners read it to understand the architectural relationship between PreseMaker and AI services.

Overview of Supported AI Providers

An explanatory reading that introduces the concept of AI providers, profiles the supported options (including Anthropic Claude and Google Gemini), and explains how the choice of provider affects content quality, style, and cost; learners use it to compare providers before selecting one.

Topic Detail .html
Understanding API Keys

An explanatory reading that defines what an API key is, why PreseMaker requires one to communicate with external AI services, and how it functions as a credential authenticating requests; learners read it to understand the purpose and importance of API keys before obtaining their own.

Topic Detail .html
Obtaining Your API Key

A step-by-step guide that walks learners through selecting an AI provider, creating an account on that provider's platform, and generating an API key so they are ready to connect PreseMaker to their chosen AI service.

Topic Detail .html
Entering Your API Key in PreseMaker Settings

A procedural guide that shows learners exactly how to open PreseMaker's Settings screen, paste their API key into the correct field, and save the configuration so the application can begin making authenticated requests to the AI provider.

API Key Encryption and Local Storage

An informational reading that explains how PreseMaker encrypts and stores API keys locally on the user's device, where the key resides, and what happens to it during normal use, helping learners assess the security implications of adding their key to the application.
