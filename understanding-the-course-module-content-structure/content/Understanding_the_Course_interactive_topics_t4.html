How PreseMaker Stores Files on Your Computer

▶

Understanding how PreseMaker stores your work on your computer is fundamental to working confidently with the application. Unlike web-based tools that save your content to a remote server, PreseMaker is a local desktop application — meaning every file it creates lives directly on your own machine. This gives you complete control over your content, but it also means you are responsible for knowing where your files are, how they are organized, and how to keep them safe. This topic walks through all of that in detail.

Local Storage: Where PreseMaker Saves Your Files

Every time PreseMaker generates or updates content — whether that is a lesson, a presentation, or a quiz — it writes the resulting files directly to a designated folder on your local hard drive or SSD. This happens on your computer, not on any external server. There is no upload step, no synchronization with a cloud account, and no dependency on an internet connection for your files to be saved.

This local-first approach has several practical consequences worth understanding:

  • Your files are always accessible offline. Because nothing is stored remotely, you can open, edit, copy, or move your files at any time without needing to log in to a service or have a network connection.
  • Your work is not affected by account status. If a subscription lapses or you uninstall the application, the files you have already generated remain on your computer exactly as they were. PreseMaker does not lock or revoke content that has been saved locally.
  • You navigate to your files just like any other folder. Open File Explorer on Windows or Finder on macOS, browse to the PreseMaker storage location, and your files are there — no special tool or export step required.

Default File Location and Folder Structure

When you first set up PreseMaker, it creates a root folder in a standard, easy-to-find location on your computer. On most systems this is inside your Documents directory, resulting in a path such as Documents/PreseMaker on macOS or C:\Users\YourName\Documents\PreseMaker on Windows.

Inside that root folder, PreseMaker uses a structured hierarchy that mirrors the way you organize content inside the application itself:

  • One subfolder per course. Each course you create gets its own named subfolder inside the root PreseMaker directory. For example, a course called "Introduction to Marketing" might appear as Documents/PreseMaker/Introduction to Marketing/. This keeps projects cleanly separated so files from one course never mix with another.
  • Modules and content nested within their course folder. Inside each course folder, PreseMaker organizes modules and their associated files in nested subfolders that reflect the logical hierarchy you see in the application's interface. If your course has three modules, you will find three corresponding subfolders, each containing the files generated for that module's lessons, presentations, and quizzes.

This mirrored structure means that if you know where something is in the PreseMaker interface, you can predict almost exactly where to find the corresponding file on disk — which makes manual file management straightforward.

File Formats Used by PreseMaker

PreseMaker deliberately saves content in widely supported, non-proprietary formats. This is a significant advantage: you never need PreseMaker itself to open, read, or edit the files it generates. The following table summarizes the content types and their corresponding file formats:

Content Type File Format(s) Opens With
Text Lessons HTML, Markdown (.md) Any web browser, any text or Markdown editor
Presentations PowerPoint (.pptx) Microsoft PowerPoint, Google Slides, LibreOffice Impress
Quiz Banks QTI (.xml), WPProQuiz (.json) LMS platforms (Canvas, Moodle, etc.), WPProQuiz plugin
  • HTML and Markdown for lessons mean your text content is both human-readable in any plain-text editor and immediately renderable in a browser for a polished, interactive or printable view.
  • .pptx for presentations is the industry-standard PowerPoint format, compatible with every major presentation application. You can open, brand, and modify slides without ever returning to PreseMaker.
  • QTI and WPProQuiz for quizzes are the dominant formats for importing assessments into learning management systems. QTI (Question and Test Interoperability) is supported by platforms such as Canvas, Blackboard, and Moodle, while WPProQuiz is the standard for WordPress-based eLearning sites.

Because none of these formats are proprietary to PreseMaker, you are never locked in. Your content belongs to the open ecosystem of tools that already exists around these standards.

Ownership and Access Rights to Your Files

PreseMaker does not claim any rights over the content you create. You retain full intellectual property ownership of everything you generate through the application. This applies to the raw files on disk as much as to the ideas and material inside them.

  • No DRM or license flags. There are no digital rights management controls, license keys, or hidden flags embedded in your saved files. A .pptx file generated by PreseMaker is an ordinary .pptx file — nothing more.
  • Full freedom to copy, move, share, or delete. You can drag your course folder to a USB drive, attach a file to an email, upload it to a shared drive, or delete it permanently — all without interacting with PreseMaker at all. The application has no say in what you do with files once they are written to disk.
  • No account-gated access. Because the files live locally and carry no license restrictions, a colleague without a PreseMaker account can open and use the output files just as freely as you can.

Locating and Verifying Your Saved Files

PreseMaker provides built-in ways to help you confirm exactly where a file has been saved after it is generated. Immediately after content is created, the application typically displays the full file path or offers a Show in Folder button that opens your operating system's file explorer directly to the location of the new file. Clicking that button is the fastest way to confirm the file exists and is in the expected place.

If you want to review or change the default save location at any point, you can do so through the application's Settings or Preferences panel. This panel shows the current root folder path and allows you to browse to a different location — useful if, for example, you want to save directly into a folder that is already being synced by a cloud storage service like Dropbox or OneDrive.

Developing the habit of verifying the file location before you close a project is well worth the few seconds it takes. Because PreseMaker is a local application with no server-side backup, a file that is not where you expect it to be — or that was accidentally saved to a temporary directory — could be difficult to recover later.

Managing and Backing Up Your PreseMaker Files

Because PreseMaker keeps no copy of your work on any server, you are the sole guardian of your files. This makes a simple, consistent backup practice essential.

  • External drive or cloud backup. Regularly copying your entire PreseMaker root folder to an external hard drive, a USB drive, or a cloud storage service (such as Google Drive, Dropbox, or OneDrive) protects you against hardware failure. If your computer's drive fails, a cloud-synced or externally backed-up copy means you lose nothing. The simplest approach is to point your cloud sync tool at the PreseMaker root folder so it is backed up automatically and continuously.
  • Version control by duplication. Before making significant edits to a file — restructuring a presentation, rewriting a lesson, or regenerating a quiz — duplicate the file and rename the copy with a date stamp or version number, for example Module3_Lesson1_v2_2025-06-01.pptx. This preserves the previous iteration and allows you to roll back if the new version does not work out. This is a lightweight alternative to formal version control systems and is sufficient for most individual authors.
  • Deletion is permanent. There is no recycle bin on PreseMaker's end. If you delete a file from your computer — or empty your operating system's recycle bin after moving a file there — it is gone. PreseMaker has no server-side copy to restore from, and it does not maintain its own version history. This is why verifying file locations and maintaining backups are not optional niceties; they are the only safety net available.

Taken together, these practices ensure that the power of local, offline file storage works in your favor: you have full control, full ownership, and fast access — as long as you also take on the responsibility of keeping your files safe.
