Using PreseMaker

Configuring AI Providers per Task and Using the Prompt Button

This module walks through how to assign AI providers to specific task types in PreseMaker, understand how tasks are routed to providers, and use the Prompt button to inspect and refine the exact text sent during generation. You'll also learn how to diagnose and respond to generation failures when they occur.
