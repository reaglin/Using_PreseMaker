Configuring AI Providers per Task and Using the Prompt Button — Topic Prompt (Source)

Module: Configuring AI Providers PreseMaker sends its generation requests to the AI providers you have configured. This module explains how to assign providers to tasks, how PreseMaker picks a provider, how to see the exact prompt, and what happens when a request fails. AI tasks are text tasks. Everything PreseMaker asks an AI provider to do is text-based: generating module topics, learning outcomes, presentation slide content, text lessons, quiz questions, assignments, interactive-activity content, speaker narration, and standards. PreseMaker does not generate images, and there is no "vision" or "image generation" task — do not imply one exists. Assigning a provider per task type. In Settings, PreseMaker lets you choose which configured provider handles each type of task, and it has a single default provider used for any task you have not assigned specifically. This lets you, for example, use one provider for slide generation and another for quizzes, based on cost, speed, or quality. How PreseMaker selects the provider (the router). When PreseMaker runs a task, it simply looks up the provider assigned to that task type — or the default provider if none is assigned — and uses it. There is no priority ranking of providers and no automatic fallback to a second provider. One task type maps to exactly one provider. Seeing the exact prompt. Every screen that sends a prompt to an AI provider has a Prompt button that shows you the exact text being sent, before or after generation, so you always know what the AI received. When a request fails. If the assigned provider fails — a missing or invalid API key, a rate limit, a network problem, or a model/endpoint error — PreseMaker shows a failure dialog that explains the problem and offers to open Settings, add a new key, or view the log.
