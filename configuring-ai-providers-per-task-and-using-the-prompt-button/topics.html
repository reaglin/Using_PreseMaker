How PreseMaker Routes Tasks to Providers

Describes the logic PreseMaker uses to select the correct provider when running a task, including the role of the default provider. Clarifies that there is no priority ranking or automatic fallback between providers.
  • The Role of the Default Provider — PreseMaker maintains a single default provider that acts as a catch-all for any task type you have not explicitly assigned to a specific provider.
  • Per-Task Provider Assignment — PreseMaker lets you assign a distinct provider to each individual task type, giving you precise control over which AI service handles each kind of generation work.
  • The Routing Logic: One Task, One Provider — When PreseMaker runs a task, its router performs a straightforward lookup: find the provider assigned to that task type, or use the default if none is assigned.
  • No Priority Ranking Between Providers — PreseMaker does not rank configured providers in any order of preference or priority when selecting which one to use for a task.
  • No Automatic Fallback Between Providers — If the assigned provider for a task cannot be reached or fails, PreseMaker does not automatically switch to another configured provider.

Using the Prompt Button

Explains how to use the Prompt button available on every generation screen to inspect the exact text sent to an AI provider. Covers when and why learners would use this feature before or after generation.
  • What the Prompt Button Is — Every generation screen in PreseMaker includes a Prompt button that gives you direct visibility into the exact text being sent to the AI provider.
  • Inspecting the Prompt Before Generation — You can open the Prompt button before triggering generation to preview exactly what will be sent to the AI provider.
  • Inspecting the Prompt After Generation — The Prompt button remains accessible after generation has completed, allowing you to review what was actually sent when a result was produced.
  • Why Prompt Transparency Matters — Seeing the exact prompt sent to a provider ensures you always know what the AI received, removing ambiguity about the source of any generated output.
  • The Prompt Button Across All Task Types — Because PreseMaker's AI tasks span a wide range of content types, the Prompt button is provided universally so no task is opaque to the user.
