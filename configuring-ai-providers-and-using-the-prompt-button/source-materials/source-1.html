Configuring AI Providers PreseMaker sends its generation requests to the AI provider you have configured. This module explains how to obtain and enter an API key, how PreseMaker picks the provider it uses, how to see the exact prompt, and what happens when a request fails. AI tasks are text tasks. Everything PreseMaker asks an AI provider to do is text-based: generating module topics, learning outcomes, presentation slide content, text lessons, quiz questions, assignments, interactive-activity content, speaker narration, and standards. PreseMaker does not generate images, and there is no "vision" or "image generation" task — do not imply one exists. The four providers and their API keys. PreseMaker works with four AI providers: Claude (Anthropic), Gemini (Google), GPT-4o (OpenAI), and Mistral AI. You obtain an API key from the provider and enter it in Settings; PreseMaker encrypts each key with Windows DPAPI and stores it in app_settings.json under your user profile. Keys are never stored in a course or shared with a repository. You do not need keys for all four — one is enough. ONE active provider is used for EVERY AI feature. This is the single most important fact in this module and it must be stated exactly. In Settings there is an Active AI Provider dropdown, and whichever provider you select there handles every AI task PreseMaker performs — module topics, learning outcomes, slide content, text lessons, quizzes, assignments, interactive activities, narration, and standards alike. There is NO per-task provider assignment. Do not describe choosing a different provider for different kinds of work. There is no routing table, no per-task dropdown, no "default provider for unassigned tasks," and no way to send slide generation to one provider and quizzes to another.
