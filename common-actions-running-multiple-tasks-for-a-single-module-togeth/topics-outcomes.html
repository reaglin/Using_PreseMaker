Module Topics

Introduction to the Common Actions Hub

An overview of the per-module Common Actions hub and its purpose as a centralized interface for managing multiple generation tasks. This topic establishes what Common Actions is and where it fits within the instructor workflow.
  • What Is the Common Actions Hub? — The Common Actions hub is a centralized interface within each module that allows instructors to manage and run multiple generation tasks in one place.
  • Purpose of the Common Actions Hub — The primary purpose of the Common Actions hub is to streamline the instructor workflow by enabling multiple generation tasks to be selected, configured, and executed together.
  • Where Common Actions Fits in the Instructor Workflow — Common Actions sits at the module level of the course-building process, making it a key stop for instructors after module content has been defined and before final review.
  • Types of Tasks Available in the Hub — The Common Actions hub presents a set of generation task options that instructors can select and configure for their module, covering a range of common instructional asset types.
  • Running Tasks Together in One Step — A defining feature of the Common Actions hub is the ability to run all selected and configured tasks together in a single operation, one after another, rather than starting each one manually.

Selecting and Configuring Generation Tasks

Covers how instructors choose which tasks to include — such as a document per topic, a multiple-choice quiz, or a presentation — and configure the settings for each. Learners will understand the options available and how to tailor each task before running.
  • Accessing the Common Actions Hub — The Common Actions hub is the central location within a module where instructors go to select and configure multiple generation tasks at once.
  • Understanding the Available Generation Tasks — Within the Common Actions hub, instructors can choose from several distinct task types designed to produce different types of learning content.
  • Selecting Which Tasks to Include — Before running, instructors must actively choose which generation tasks they want to execute for the module.
  • Configuring Settings for Each Task — After selecting tasks, instructors configure the specific settings for each one to tailor the output to their needs.
  • How Common Actions Remembers Settings Per Course — Common Actions includes a memory feature that retains the task configurations an instructor has previously set, scoped to each individual course.
  • Tailoring Quiz Generation with Per-Topic Settings — The multiple-choice quiz task includes an option to generate quizzes on a per-topic basis rather than across the module as a whole.

Running Multiple Tasks Together in One Step

Explains how the Common Actions hub lets instructors run all selected and configured tasks together in a single operation, one after another, rather than starting each one manually. This topic highlights the efficiency gains of batching generation tasks into a single run.
  • What the Common Actions Hub Is — The Common Actions hub is a centralized interface within each module that consolidates multiple generation tasks into one location.
  • Selecting and Configuring Tasks Before Running — Before executing tasks, instructors choose which tasks they want to run and configure any relevant settings for each one.
  • Running All Selected Tasks Together in One Step — Once tasks are selected and configured, the Common Actions hub allows instructors to execute all of them together with a single action.
  • Efficiency Gains from Batching Generation Tasks — Batching multiple tasks into a single run significantly reduces the time and effort required to produce a full set of module materials.
  • How Common Actions Remembers Settings Per Course — The Common Actions hub retains the task configurations an instructor has set, so they do not need to reconfigure from scratch each time.

Persistent Settings Per Course

Describes how Common Actions remembers configuration settings on a per-course basis so instructors do not need to reconfigure tasks each time they return. This topic explores the practical time-saving benefit of this memory feature.
  • What 'Persistent Settings' Means in Common Actions — Persistent settings refer to the ability of Common Actions to automatically save and retain the configuration choices an instructor makes for a given course.
  • Per-Course Scope of Saved Settings — Settings are remembered on a per-course basis, ensuring that each course retains its own unique configuration independently of other courses.
  • Time-Saving Benefit of Settings Memory — The primary practical advantage of persistent settings is that instructors save significant time by eliminating repetitive reconfiguration work each time they return to a course.
  • Consistency Across Module Processing — Because settings persist, every module within a course is processed using the same task configuration, promoting consistency in the instructional materials produced.
  • Returning to a Course After a Break — Persistent settings are particularly beneficial when instructors return to a course after a period of time, such as between semesters or after a workflow interruption.

Per-Topic Quiz Generation and Reliability

Examines why generating quizzes on a per-topic basis produces more reliable and accurate results compared to generating a single quiz for an entire module. This topic explains the reasoning behind this approach and its impact on quiz quality.
  • The Challenge of Module-Level Quiz Generation — Generating a single quiz for an entire module at once can introduce reliability issues and reduce the overall quality of the output.
  • Why Per-Topic Quiz Generation Works Better — Generating quizzes on a per-topic basis means the system focuses on one discrete topic at a time, producing more targeted and accurate quiz questions.
  • Impact on Quiz Accuracy and Question Quality — The accuracy of individual quiz questions is directly tied to how well the source content is scoped during the generation process.
  • Reliability Across the Full Module — Running per-topic quiz generation as part of a combined Common Actions task ensures consistent reliability across all topics in the module.
  • Per-Topic Quizzes and Alignment with Learning Objectives — Generating quizzes at the topic level supports stronger alignment between quiz questions and the specific learning objectives of each topic.
